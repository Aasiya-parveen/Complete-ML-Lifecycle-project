# Complete ML Lifecycle Project

This project demonstrates the complete Machine Learning lifecycle using Hugging Face Transformers, Flask API, and Docker.

## Features
Fine-tuning pretrained NLP model
IMDb sentiment analysis
Batch inference
Flask REST API
Docker containerization
Google Colab implementation

## Technologies Used
 Python
 Transformers
 PyTorch
 Flask
 Docker
